# Proposal: M4 数据可移植性、桌面集成与 v1.0 发布

## Why

M1–M3 已交付本地多库存储、加密笔记、任务与日程三大核心模块，但用户仍缺少可靠迁移和恢复数据、从常见格式交换内容、从系统级入口快速操作应用的能力，当前产品也仍使用模板元数据与单一中文界面，尚不具备 v1.0 分发条件。M4 完成 `spec.md` 里程碑中剩余的导入导出、备份、快捷键、托盘和发布打磨，使离线数据真正可带走、可恢复，并形成可发布的跨平台桌面产品。

## What Changes

- 新增笔记导入导出：导入 Markdown、HTML、纯文本；将单页或分区导出为 Markdown、HTML、PDF，并支持打印；加密分区必须先解锁，导出内容由用户明确确认后才以明文离开加密边界
- 新增日历 iCalendar 互操作：导入与导出 `.ics`，保留已支持的 RRULE、时区、全天事件和例外；农历重复事件导出为指定范围内的公历实例集合
- 新增完整备份与恢复：生成包含主库、领域库、空间库及附件的单一版本化备份包；写入前建立 SQLite 一致性快照；恢复前校验清单与文件哈希并保护当前数据；加密分区始终保持密文；支持用户指定目录的定时自动备份与最近 N 份保留
- 新增全局命令面板：聚合笔记、任务、日程搜索结果，并提供快速新建笔记/任务、跳转和锁定全部加密分区等操作；锁定分区内容继续遵守既有搜索隔离
- 新增可自定义的应用内与系统级快捷键，默认覆盖命令面板、快速笔记、快速任务和锁定全部加密分区；冲突或系统注册失败时给出可恢复提示
- 新增系统托盘：最小化到托盘、恢复/隐藏主窗口、快速新建、锁定全部分区和退出；退出路径先锁定并清零会话密钥
- 完成 v1 通用体验：中英文界面、亮色/暗色/跟随系统主题、统一设置页、跨模块标签汇总与筛选、笔记页面模板，以及笔记待办项创建关联任务的轻量联动
- 完成 v1.0 发布工程：替换模板名称与元数据，固定应用标识和版本，配置 Windows/macOS/Linux 安装包与图标，补齐发布文档、许可与数据恢复说明，并建立跨平台构建、升级兼容、键盘可访问性、性能和安装包烟雾验证

不在本变更范围：云同步或多人协作、移动端、OneNote `.one` 导入、录音、自由画布、任务自然语言日期解析、应用内自动更新及安装包签名/公证凭据管理。

## Capabilities

### New Capabilities

- `data-portability`: 笔记 Markdown/HTML/纯文本导入，笔记 Markdown/HTML/PDF 导出与打印，以及日历 iCalendar 导入导出的行为与安全边界
- `backup-recovery`: 多库与附件的一致性备份包、校验恢复、自动备份计划、保留策略及故障处理
- `desktop-experience`: 全局命令面板与跨模块搜索、自定义快捷键、系统托盘、主题、多语言和统一设置体验
- `release-readiness`: v1.0 应用身份、跨平台安装包、升级兼容、发布文档以及性能与可访问性发布门槛

### Modified Capabilities

- `notes-module`: 增加页面模板、跨模块标签汇总、笔记待办与任务的轻量联动，并明确笔记导入导出入口与加密分区解锁约束
- `calendar-module`: 增加 `.ics` 导入导出入口及农历重复事件的有界公历展开规则
- `tasks-module`: 增加全局快速创建、统一标签汇总和笔记待办关联任务的交互契约
- `data-storage`: 增加备份/恢复过程中的一致性快照、恢复校验和启动失败回退要求
- `app-skeleton`: 增加系统托盘生命周期、平台安装包产出、应用身份与发布配置要求

## Impact

- **Rust 后端**：新增 `import_export/`、`backup/` 与桌面集成模块；扩展 commands、搜索聚合、设置、应用生命周期和数据库快照/替换流程；新增备份清单格式与必要的版本化迁移
- **React 前端**：新增命令面板、设置、备份恢复、导入导出、标签汇总、模板选择与发布级错误反馈；抽取可本地化文案与主题 token；扩展三大模块的快速创建和关联入口
- **Tauri 与依赖**：引入 dialog、fs、global-shortcut、single-instance 等所需官方插件及托盘能力；按平台配置 bundle 元数据、资源与权限
- **数据与兼容**：现有数据库原位向前迁移；备份格式带 schema/app 版本、逐文件哈希与原子恢复协议；恢复只接受受支持版本，失败时保留原数据；加密内容在备份中不解密
- **安全**：明文导出需显式目标与确认；路径处理防止目录穿越和覆盖未确认文件；退出、托盘隐藏与恢复过程不延长解锁会话；日志不得包含笔记正文、密钥或密码
- **风险**：HTML/PDF 跨平台渲染差异、iCalendar 客户端兼容、运行中多库一致性快照、全局快捷键冲突、不同桌面环境的托盘行为，以及跨平台发布产物验证
