# Tasks Module Spec Delta

## ADDED Requirements

### Requirement: 全局快速创建任务
任务模块 SHALL 接受来自命令面板、全局快捷键和托盘的快速创建请求；未指定列表时任务进入默认收件箱，用户可在保存前设置标题、截止时间与列表。取消 SHALL 不创建记录。

#### Scenario: 后台快速创建
- **WHEN** 用户从系统级快捷键打开快速任务并只输入标题后保存
- **THEN** 新任务进入默认收件箱且主窗口可导航到该任务

### Requirement: 任务参与统一标签汇总
带全局标签的任务 SHALL 出现在统一标签视图并支持按任务类型筛选、完成状态显示与跳转；归档任务默认排除且用户可显式包含。

#### Scenario: 默认排除归档任务
- **WHEN** 用户查看标签汇总且一个匹配任务已归档
- **THEN** 该任务默认不显示，启用“包含归档”后显示且标记为已归档

### Requirement: 任务与笔记待办关联
由笔记待办项创建的任务 SHALL 保存来源页面与待办节点引用。任务完成或恢复为未完成后，系统 SHALL 更新可访问来源页面的对应待办状态；来源分区锁定时 SHALL 延迟同步且不得解密或泄露内容。

#### Scenario: 来源分区锁定时完成任务
- **WHEN** 用户完成一个来源页面处于锁定加密分区的关联任务
- **THEN** 任务正常完成，系统记录待处理同步且不读取页面，分区下次解锁后更新待办状态
