# Release Readiness Spec Delta

## Purpose

定义 Tenjee Vault v1.0 的稳定应用身份、跨平台可安装产物、升级兼容、用户文档及可验证质量发布门槛。

## ADDED Requirements

### Requirement: 稳定应用身份与平台安装包
系统 SHALL 以“Tenjee Vault”产品名、稳定反向域名标识、语义化版本和正式图标构建 Windows、macOS 与 Linux 安装包。各平台产物 SHALL 安装、启动、创建数据目录并可卸载；升级安装 SHALL 复用同一应用身份和数据目录。

#### Scenario: 三平台发布构建
- **WHEN** 对 v1.0 标签执行受支持平台构建
- **THEN** Windows、macOS 与 Linux 分别产出可安装包，包内版本与标签一致且不包含开发服务器依赖

#### Scenario: 从先前版本升级
- **WHEN** 用户在已有 M1–M3 数据目录上安装 v1.0
- **THEN** 应用原位运行缺失迁移，保留全部数据与偏好并正常打开三个模块

### Requirement: 发布文档与数据主权说明
发布包或项目文档 SHALL 提供安装与卸载方法、受支持平台、数据目录位置、备份恢复步骤、加密密码不可恢复说明、已知限制、第三方许可和版本变更摘要。文档 SHALL 明确卸载是否保留用户数据以及安全删除方法。

#### Scenario: 用户查找恢复说明
- **WHEN** 用户在应用帮助或随包文档中查找备份恢复
- **THEN** 可找到与当前版本一致的创建、校验、恢复与失败回退步骤

### Requirement: v1.0 质量门槛
v1.0 发布候选 SHALL 通过 Rust 与前端自动化测试、三平台构建和安装启动烟雾验证、从最近已发布数据版本升级验证、备份恢复往返验证、全键盘核心流程检查及性能基线检查。阻断级失败 SHALL 阻止发布产物被标记为 v1.0。

#### Scenario: 发布候选存在阻断失败
- **WHEN** 任一平台安装后无法启动、恢复往返哈希不一致或核心键盘流程不可完成
- **THEN** 发布流程失败且不会发布 v1.0 版本

#### Scenario: 性能基线
- **WHEN** 在规定基准硬件和已初始化数据集上测量冷启动与十万页面搜索
- **THEN** 冷启动低于 2 秒且搜索结果在 300ms 内返回，测量结果随发布记录保存
