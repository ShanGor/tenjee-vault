These variable WOFF2 fonts match sam-blog's reading typography and are bundled
locally so notes render without network access:

- Fraunces: headings, weights 400–700
- Source Sans 3: body text, weights 400–700
- JetBrains Mono: code, weights 400–600

Downloaded from Google Fonts (fonts.gstatic.com). `fonts.css` retains the original
language subsets and Unicode ranges. Chinese uses the platform font fallbacks
declared in App.css. Each family is distributed under the SIL Open Font License;
the original licenses from https://github.com/google/fonts are included here.
